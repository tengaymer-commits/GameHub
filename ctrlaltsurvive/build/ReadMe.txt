CTRL+ALT+SURVIVE 2003
=====================

PLAY
  Double-click CtrlAltSurvive.exe.
  The game opens in its own window. It uses Microsoft Edge (built into
  Windows) or Google Chrome to draw the game. Nothing gets installed.
  Close the window to quit, or use Start > Turn Off Computer in the game.

  Can't run an .exe? Open CtrlAltSurvive.html in any modern browser instead.

SAVES
  The .exe keeps your progress in %LOCALAPPDATA%\CtrlAltSurvive2003\
  Delete that folder (or empty the in-game Recycle Bin) to start over.
  The .html file keeps a separate save inside the browser you open it with.

WINDOWS SMARTSCREEN
  The .exe is not code-signed, so Windows may show "Windows protected your PC".
  Click "More info", then "Run anyway".

CONTROLS
  WASD / arrow keys to move (or hold and drag with the mouse or on touch).
  Esc or P pauses (Task Manager). Keys 1-4 then Enter pick level-up options.
